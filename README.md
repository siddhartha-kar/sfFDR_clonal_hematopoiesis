R scripts accompanying the manuscript, "Shared genetics of blood traits identify clonal hematopoiesis risk loci and a polygenic predictor of leukemia risk". The sfFDR, pgs, cS2G, and figures folders contain the code used for the surrogate functional false discovery rate analysis, polygenic score analysis, combined SNP-to-gene analysis, and plotting figures, respectively.
