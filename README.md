R scripts accompanying the manuscript, *"Shared genetics of blood traits identify clonal hematopoiesis risk loci and a polygenic predictor of leukemia risk"*.

The [`sfFDR`](./sfFDR), [`pgs`](./pgs), [`figures`](./figures), and [`misc`](./misc) folders contain the code used for the surrogate functional false discovery rate analysis, polygenic score analysis, plotting figures, and miscellaneous analyses, respectively.
